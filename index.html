How to use Event Horizon
Open the sections below. Press ? anywhere for hotkeys and Ctrl/Cmd+K to jump to anything.


Getting around
The left menu opens each section. Ctrl/Cmd+K searches notes and sections. The ~ key opens a terminal: orbit focus 25, node create "Physics", open stats, theme red. Voice commands (Station config) understand "Computer, start timer".


Starmap
Each note is a star. Brighter means reviewed more. Notes sharing a tag or subject join into a constellation. Arrow keys move between stars, Enter opens the note. Press M on one star, move to another and press L to draw your own line (press again to remove it). Station config has an ecliptic grid, tag colours are set in Notes, and Starmap PNG downloads a picture.


Notes
Tabs along the top are subjects. Write Markdown and LaTeX ($x^2$). The toolbar inserts LaTeX, templates, and pastes images (paste a screenshot). Use [[Note title]] to link notes; backlinks show under the editor. Callouts: > [!warning] text, [!log], [!memo]. Snapshots save automatically every few seconds of editing; pick one and Restore. Pin keeps a note in the tray at the bottom. Select a phrase and press Make cloze card. Present slides splits on ## headings or --- lines. Share link encodes the note in the URL (not encrypted). Print / save PDF gives a clean page.


Flashcards
Add cards on the right, flip with a click, then grade. The coloured dots show how often you missed each card. Reverse swaps front and back, 5 s lightning flips cards for you, the interval slider scales review gaps, and the ring shows how many cards are mastered. Cards accept Markdown. Export and import decks as JSON.


Timer, ranks and status
The Focus timer runs focus and break cycles with a warp sound, optional notifications and a reflection prompt. Zenith lockout stops you leaving the timer. Station status shows distance travelled, hull integrity, solar flare bonus, colonisation, trophies, and a weekly report you can copy, share or download as an image.


Maths and science tools
Calculator, Math engine (calculus, matrices, grapher, errors), Geometry & orbits (Argand, sketchpad, Kepler, Moon), Astro tools (H-R diagram, spectra, relativity, field of view, coordinates), Orbital lab, Physics lab (seven simulations with sliders) and Sky lab (transit curve, meteor radiants, solar system scale, spectral quiz).


Dev bench and Code lab
Dev bench has a JavaScript console (runs in a worker), HTML preview, regex tester, Markdown table builder, JSON tree, colour converter, Base64 and a note link checker. Code lab lets you pick from 14 languages. JavaScript, Python, Lua, SQL, Brainfuck and HTML run inside your browser (Lua, SQL and Python download a runtime the first time). C, C++, Java, Rust, Go, Ruby, PHP and TypeScript run through an online service when it is reachable. Export code saves the editor as a file with the right extension, Import code loads a file and picks the language from its extension, and the vault can be exported and imported as JSON.


Sound
Music makes endless ambient audio. Station config holds the Audio lab: planet soundscapes, noise filters, binaural sweep, chime designer and Morse. Mute silences everything. The small bars next to it show the sound.


Look and system
Station config changes blur, glow, font, themes, background image, aurora, minimalist view, kiosk mode and the starfield. Supernova alert turns the header red when a deadline is within 3 days. The site installs as an app and works offline.


Saving and backups
Everything saves automatically in this browser and syncs between open tabs. Export station JSON for a backup file, and import it on another device. The site reminds you monthly. Factory reset erases everything.


Memory lab and study rhythm
Memory lab shows your Leitner sectors (cards move up a planet when you recall them and drop to Mercury when you forget; Review this sector filters the flashcards), a 28-day review workload map, active recall questions, a 5-minute sleep review, a doodle pad linked to your current note, a self-clearing mental sandbox and a concept matcher built from **bold** terms. Turn on interleaving and the pacemaker, and list conflicting subject pairs, for gentle warnings.


Solver bench
Pick a tool from the list, fill in the boxes and press Run: matrix, chemical balancer, kinematics, Ohm's law, polar/rectangular, percent error, hypothesis tests, bitwise, Riemann sums, Big-O curves, data structures, growth models, trig circle, Markdown table to JSON, ASCII flowchart, Git simulator, citations, and text analysis of your current note (keywords, readability, complexity, summary, questions, duplicates, spelling, flashcards, orphans, vault health).


Starmap tools
The panel on the starmap offers gravity clustering, orphan highlighting, fog of war, star sizing by mastery, words or references, filters, a timeline slider and isolation (or press I). Hover a star to preview it and its linked notes. Set each note's priority in Notes to ring its star. The tree on the left lists subjects and notes (double-click to open). Export storyboard saves a star and its neighbours as a study guide.


Mission board, missions and security
Mission board has tasks (Eisenhower and Kanban views, drag to move), burn-down, time-box dial, interruption logger, streak freeze, sinkhole and the daily briefing. Missions & arcade has two mini-games, the Voyager campaign, captain's log, commander profile and galaxy milestones. Security & vault has encrypted export, QR deck transfer, storage monitor, PIN gate, vault health check, cache verification and a printable portfolio.


Troubleshooting
Stuck on an old version: reload twice or hard refresh. No sound: click a sound button first, browsers need a click. Live feeds blank: NASA's demo key is rate limited.
